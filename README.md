# ft_newton

A 3D rigid-body physics engine written from scratch in C, demonstrated through a trebuchet-versus-structures game rendered with OpenGL 3.3.

See [docs/README.md](docs/README.md) for the description, build instructions, controls and the object file format, and [docs/PHYSICS.md](docs/PHYSICS.md) for every formula the engine implements.

```bash
make && ./newton
```
